# A Nireesh - 3D Cyber Security Analyst Portfolio

A modern, highly interactive, production-quality 3D portfolio website for **A Nireesh**, Junior Cyber Security Analyst & Cybersecurity Student.

Built with a **Cybersecurity Command Center / Digital Universe** visual theme, dark black background, neon green and cyan accents, glassmorphism cards, interactive 3D Three.js models, Framer Motion animations, and responsive Tailwind CSS layout.

---

## 🚀 Tech Stack

- **Framework**: React 18 + Vite
- **3D Graphics Engine**: Three.js / `@react-three/fiber` / `@react-three/drei`
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Styling**: Tailwind CSS with custom cyber utilities & glassmorphism
- **PDF Resume Engine**: jsPDF dynamic generation

---

## 🛡️ Key Features

1. **3D Cyber Shield Landing Hero**: Interactive rotating 3D shield with binary rings, laser scanning line, lock core, and mouse-parallax movement. Includes animated typing effect for role titles.
2. **About Me Matrix**: Verified personal metrics, language badges, and animated scroll-triggered stats counters.
3. **Interactive 3D Skill Constellation & Progress Cards**: R3F 3D Skill Orbit system with connected nodes, progress bars, and hover tooltips.
4. **3D Project Cards & Modals**:
   - *Secure Web Application with Authentication & Intrusion Detection System* (Spring Boot, BCrypt, MySQL, REST API, failed attempt lockouts, security scanner visualizer).
   - *Smart AI Learning for School Education* (React, Node.js, AWS, AI Chatbot, neural network visualizer).
5. **Academic Timeline**: Glowing vertical timeline highlighting B.Tech in CS & Cyber Security (GPA 8.5) and college milestones.
6. **Verified Certification Card**: Certified Ethical Hacker (CEH) by EC-Council with holographic border.
7. **Interactive Resume Download**: 3D floating document model and single-click PDF resume download (`Nireesh_Resume.pdf`).
8. **Hacker Terminal Contact Interface**: Command-line styled contact form with real-time payload validation and live console feed.

## 📦 Installation & Setup

1. **Clone or Navigate to the Project**:
   ```bash
   cd nireesh-cyber-portfolio
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Start Development Server**:
   ```bash
   npm run dev
   ```
   Open your browser at `http://localhost:3000`.

4. **Build for Production**:
   ```bash
   npm run build
   ```

---

## 🌐 Deploy to Vercel or Netlify

### Deploying to Vercel
1. Push this repository to GitHub/GitLab.
2. Go to [Vercel](https://vercel.com) and click **Add New Project**.
3. Select your repository.
4. Framework Preset: **Vite**.
5. Click **Deploy**.

### Deploying to Netlify
1. Connect your repository on [Netlify](https://netlify.com).
2. Build command: `npm run build`
3. Publish directory: `dist`
4. Click **Deploy Site**.
